Alu Asistencias

Sistema de control de asistencia empresarial

Versión 1.0

📌 Descripción del sistema

Alu Asistencias es una plataforma desarrollada para la gestión, administración y control de asistencias del personal de Alupratic S.A. de C.V.

El sistema permite administrar trabajadores, sedes, calendarios laborales, eventos especiales, reportes de asistencia y sincronización con checadores biométricos ZKTeco mediante un servidor local.
